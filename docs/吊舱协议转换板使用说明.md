# 吊舱协议转换板使用说明

适用于 TZ130TM 吊舱、STM32 协议转换板和运行 ArduPilot 的 CUAV X7 系列飞控。交付固件为 **ID 86 启用版**，来自提交 `9d5b64a`。 [固件与插件目录](../stm32-mavlink/build/releases/tz130tm-native-9d5b64a)

## 1. 安装 Mission Planner 插件

台架使用 Mission Planner **1.3.83**。

1. 退出 Mission Planner，将交付文件 `GimbalPointingPlugin.dll` 复制到 Mission Planner 安装目录下的 `plugins` 文件夹。台架电脑的路径为 `C:\Program Files (x86)\Mission Planner\plugins`。
2. 重启 Mission Planner，用飞控 USB 口连接地面站。点选功能使用飞行数据地图中已有的 **在此放置相机（Point Camera Here）**。

## 2. 烧录 STM32 固件

1. 将 ST-LINK 的 **SWDIO、SWCLK、GND** 分别接到转换板的同名引脚，给转换板供电。
2. 打开 STM32 ST-LINK Utility，选 **Target → Connect**。用 **File → Open file** 打开 `tz130tm-id86-enabled-9d5b64a.hex`，核对文件校验值为 **`0x001B6E7C`**。
3. 选 **Target → Program & Verify**，点击 **Start**。日志出现 `Verification...OK` 后，复位转换板。 [ST-LINK Utility 手册](https://www.st.com/resource/en/user_manual/um0892-stm32-stlink-utility-software-description-stmicroelectronics.pdf)

## 3. 连接转换板

| STM32 接口 | STM32 引脚及方向 | 对端 |
| --- | --- | --- |
| USART1 | PA9（TX）→ | 飞控 TELEM2 RX |
| USART1 | PA10（RX）← | 飞控 TELEM2 TX |
| USART2 | PA2（TX）→ | 吊舱 COM TTL RX |
| USART2 | PA3（RX）← | 吊舱 COM TTL TX |
| USART3 | PB10（TX）→ | USB 转 TTL 模块 RX |
| GND | 板上 GND | 与飞控、吊舱、USB 转 TTL 模块的 GND 共地 |

串口统一使用 **115200、8N1、无硬件流控**。USB 转 TTL 模块使用 3.3 V 逻辑，接电脑后用串口助手以文本模式查看日志。各设备按自身要求供电，吊舱继续使用现有的定位和姿态输入。

首次部署时，在飞控中核对 `SERIAL2_PROTOCOL=2`（MAVLink2）、`SERIAL2_BAUD=115`（115200）和 `MNT1_TYPE=4`（SToRM32 MAVLink）。如需修改，写入后重启飞控。 [ArduPilot 云台配置](https://docs.ardupilot.org/copter/docs/common-storm32-gimbal.html)

## 4. 操作与检查

**在未解锁的台架上操作。** ID 86 是飞行位置设定值，飞控在 Guided 等支持该消息的模式下可将其作为飞行目标。 [ArduCopter 位置指令说明](https://ardupilot.org/dev/docs/copter-commands-in-guided-mode.html#set-position-target-global-int)

1. **接通设备。** 先给转换板和吊舱上电，再启动飞控。打开 Mission Planner、厂家吊舱软件和串口助手。看到 `[SYS] ready=1` 后检查吊舱画面。
2. **地图指向。** 等飞控定位有效后，在 Mission Planner 地图上右键选择 **在此放置相机**，输入目标相对 Home 的高度（米）。吊舱到位后，串口显示 `[POINT] ... event=arrived`，转换板自动暂停转发角度。
3. **跟踪并测距。** 在厂家软件画面中选中目标。看到 `[TARGET] tracking=0x01` 后，启动单次或连续测距。`[TARGET]` 显示距离和目标经纬高。
4. **确认回传。** 看到 `[UART1_TX] msgid=86 len=64 result=sent`，表示转换板已从 USART1 发送。对应坐标见 `[RANGE]`。相同测距结果会合并，新结果最多每秒发送一帧。飞控实际收包需从飞控侧确认。
5. **切换目标。** 在厂家软件结束当前跟踪和测距，再回到 Mission Planner 选新点，重复上述操作。

地图指向、到位停发、厂家软件跟踪和测距已在台架跑通。ID 86 封包已通过编译和主机回归，实机发包与飞控收包仍待确认。
